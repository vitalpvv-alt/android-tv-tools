# Данные и доступ

- В публикации нет API-ключей, OAuth-токенов, private keys, домашнего адреса ADB, снимков личного браузера и журналов конкретного владельца.
- Каждый пользователь указывает свой телевизор и свои API-ключи. Прямые локальные команды и погода не используют общий аккаунт проекта.
- Панель ПК слушает loopback и использует случайный токен с проверкой запросов. Токен живой панели и папка `reports/` не предназначены для публикации.
- TV Assistant использует службу специальных возможностей для управления интерфейсом и обработки Mi. Подсветке отдельно выдаётся системное разрешение `WRITE_SECURE_SETTINGS`; её адаптер ограничен проверенной моделью и ключом подсветки.
- SpeechRecognizer может обращаться к сервису распознавания Android. API-команды отправляются выбранному провайдеру. Погода отправляет выбранные городские координаты погодному сервису.
- Ключи API хранятся на телевизоре с защитой Android Keystore. Ключи подписи сборок не входят в исходники и установочные комплекты.

Для обычной ошибки создавайте Issue с версией Android, моделью, версией приложения и коротким воспроизводимым примером. Не прикладывайте API-ключи, пароли, полный журнал входа или архив локальной панели. При обнаружении утечки сначала отзовите соответствующий ключ у своего провайдера.
