# Сумерки ТВ1.1 · комплект Windows

Node.js20+ и ADB-отладка на своём Xiaomi MiTV-MSSP1 / Android9.
Запустите INSTALL.cmd, укажите свой IP:порт либо USB-серийный номер. Можно задать TV_SERIAL заранее.
Установщик проверяет модель, APK и picture_backlight, сохраняет исходный уровень и выдаёт приложению WRITE_SECURE_SETTINGS.
На ТВ выберите свой город, проверьте ночной уровень на 10 секунд и подтвердите автоматику после видимого изменения подсветки.
Вечерние ступени при 100/0%: 100 →75 →50 →25 →0%, утром обратно.
Остановка: кнопка в приложении либо RESTORE.cmd. Восстановите подсветку перед удалением программы.
Полная инструкция и исходники: https://github.com/vitalpvv-alt/android-tv-tools/tree/main/sunset-tv
