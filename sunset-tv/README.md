# Сумерки ТВ 1.1

Программа для **Xiaomi MiTV-MSSP1 / Android TV9**, пакет `ru.vital.tv.sunset`, code2. Рассчитывает положение солнца локально и меняет штатную подсветку панели. Для работы после установки компьютер и Интернет не требуются.

| Высота солнца | Подсветка при дневных 100% и ночных 0% |
|---|---:|
| Выше +6° | 100% |
| От +6° до +2° | 75% |
| От +2° до −2° | 50% |
| От −2° до −6° | 25% |
| Ниже −6° | 0% |

Утром ступени проходят в обратном порядке. При других дневном и ночном уровнях промежуточные значения распределяются между ними. Можно выбрать двухуровневый режим по рассвету/закату. **0% — минимум штатного регулятора, а не обещание полного выключения света панели.**

## Установка

1. Скачайте [комплект Windows](../downloads/sunset-tv-windows-v1.1.zip?raw=true), распакуйте весь архив. Нужны Node.js 20+ и ADB-отладка на своём телевизоре.
2. Запустите **INSTALL.cmd**, укажите свой адрес `IP:порт` или USB-серийный номер. Можно заранее задать `TV_SERIAL`.
3. Установщик сверит APK, модель и наличие `picture_backlight`, сохранит исходную подсветку, установит приложение и выдаст ему `WRITE_SECURE_SETTINGS` для управления системной подсветкой.
4. Выберите свой город, координаты/часовой пояс и желаемые уровни. Находка — исходный пример, а не автоматически определённое местоположение.
5. Нажмите **«Проверить ночные 0% на 10 секунд»**. Исходный уровень вернётся через 10 секунд. Если подсветка действительно изменилась, подтвердите включение автоматики.

Ручная установка:

```sh
adb -s YOUR_DEVICE install -r windows/SunsetTV_1_1.apk
adb -s YOUR_DEVICE shell pm grant ru.vital.tv.sunset android.permission.WRITE_SECURE_SETTINGS
adb -s YOUR_DEVICE shell am start -n ru.vital.tv.sunset/.MainActivity
```

Приложение использует именно аппаратный ключ `Settings.Global.picture_backlight` в диапазоне 0..100. Это не чёрный оверлей. Аппаратный адаптер отказывается менять подсветку на неизвестной модели или при отсутствии настройки. Совместимость всех Xiaomi, HDR-профилей и сторонних прошивок не заявляется.

## Остановка и восстановление

В приложении используйте **«Выключить и вернуть исходную подсветку»**, с ПК — **RESTORE.cmd**. Сначала восстанавливайте подсветку, затем удаляйте приложение: удаление пакета само по себе системное значение не возвращает.

Исходный уровень сохраняется до первой записи и не заменяется ночным значением при обновлении. Если прошивка непрерывно сбрасывает подсветку, ограничитель частоты останавливает автоматику и пытается вернуть исходный уровень. После перезагрузки и изменения часов расписание пересчитывается; ради рассвета экран не включается.

## Сборка

JDK17, Android SDK34, Build Tools34.0.0, Gradle wrapper8.9. Укажите SDK через `ANDROID_HOME` / `ANDROID_SDK_ROOT` либо `local.properties`.

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
node --test windows/*.test.cjs
```

Debug-сборка работает без ключа автора. Для своей release-подписи создайте приватную папку `signing/`, положите туда собственный `sunset-tv.jks` и `signing.properties` по примеру `signing.properties.example`. Без этой папки release остаётся неподписанным. Папка исключена из Git. Для последовательных обновлений своего APK сохраняйте один и тот же ключ.

Времена солнца сопоставлены с Astral для 168 дат/городов, границы сумерек — для 672 сочетаний высоты солнца, даты и города; 32 unit-теста. Эти проверки не доказывают работу подсветки любой прошивки. См. [VALIDATION.md](../docs/VALIDATION.md).
