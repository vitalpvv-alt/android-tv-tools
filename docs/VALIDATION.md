# Проверки публикации

Состояние приложений на **15 ноября 2026**. Публикация содержит APK из проверенных личных сборок, но не данные их владельца. Исходники опубликованы отдельным снимком без приватной истории разработки.

## ТВ-помощник code23

- APK: `dev.mert.tvassistant`, `0.2.4-xiaomi.12-search-voice`, code23, minSdk23 / targetSdk28. SHA256: `c69f0a87a1be1d8f54058df26a2813db5101a67f6bf9de5caac64972913b961a`.
- На физическом MiTV-MSSP1 / Android9 подтверждены установка, права, сохранение назначенной Mi, реальные распознанные фразы и завершение двух команд мини-движка. Содержание этих фраз диагностикой не сохраняется.
- Общий введённый запрос `Find the series Sherlock` открыл выдачу Wink, помощник перечислил наблюдаемые карточки. ИИ0, один инструмент.
- `Find Sherlock in Zona` открыл реальную выдачу Zona. Сам автоматический receipt Zona в code23 остаётся неподтверждённым; результаты отдельно проверены по интерфейсу. Запуск платного просмотра не выполнялся.
- Google Russian TTS завершил контрольную фразу с callback `spoken`. Это не подтверждение слышимости конкретного телевизора/ресивера агентом.
- Проверки исходной сборки: 87 JVM, 48 погодных, 7 поисковых; 36 Android9/Robolectric; 57 Node, включая 4 Java/Node проверки шифрования. Синтетические callbacks не считаются настоящей речью.
- Карточка погоды ранее проверена на CleanYourTV; комнатный ambient temperature sensor на проверенном ТВ отсутствует.

## Изменения для открытой публикации

Android-логика и опубликованные APK сохранены. Windows-установщики теперь спрашивают адрес устройства или берут `TV_SERIAL`, поддерживают USB-серийный номер и не содержат домашнего адреса автора. Сохранены проверки модели, APK и исходной подсветки. Сборочные пути приведены к переменным SDK. Ключи подписи, личные отчёты и локальные настройки исключены.

Результаты проверок переносимого комплекта фиксируются в `docs/PUBLICATION_CHECKS.json`. Контрольные суммы установочных архивов находятся в `downloads/SHA256SUMS.txt`.
