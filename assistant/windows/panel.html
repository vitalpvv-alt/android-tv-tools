TV Assistant · Xiaomi

MiTV-MSSP1 · Android 9. Панель нужна только во время настройки.

Готово к проверке

Подключить xKiro

Выбраны только бесплатные модели. Перед генерацией приложение проверяет их цену в каталоге xKiro.

После передачи проверь подключение, затем свободную команду на телевизоре.



Подключить OpenRouter
Вставь отдельный ключ с компьютера. Он сохранится на телевизоре; на ПК в файлы не записывается.
Передача не вызывает модель. После сохранения проверь свободную команду в помощнике.


Диагностика OpenRouter
Проверяет доступ с ПК и ТВ через сохранённый на телевизоре ключ. Повторно вводить ключ не нужно. Модель не вызывается.


Проверка ответа xKiro
Один запрос к выбранной бесплатной модели с телевизора. Проверяется JSON-план; команды управления не выполняются.
%XKIRO_START_REPORT%


Кнопка Mi и мини-помощник
Нажми «Назначить кнопку Mi», затем Mi один раз на пульте. Следующее нажатие откроет мини-окно для голосовой команды.
%VOICE_START_REPORT%


Погода на главном экране
Для проверки загрузки прогноза сначала нажми «Домой».






Экран телевизора
Нажатие по свежему изображению передаётся на ТВ. 


Проверка команды
Ввод разрешён только в выделенное поле команды TV Assistant. Для ключа OpenRouter используй отдельный блок выше.


Элементы текущего экрана
Нажми «Прочитать элементы экрана».
Установка и права
Нажми «Проверить установку и права».
