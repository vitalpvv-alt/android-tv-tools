# ТВ-помощник · комплект Windows

1. Установите Node.js 20+ с https://nodejs.org/.
2. Включите ADB-отладку на своём Xiaomi MiTV-MSSP1 / Android9 и разрешите соединение компьютера.
3. Запустите MI.cmd. Укажите свой IP:порт или USB-серийный номер. Можно заранее задать переменную TV_SERIAL.
4. При первой настройке нажмите Mi один раз для назначения, затем ещё раз и скажите «Найди сериал Шерлок».
5. Погода и простые команды работают без ИИ-ключа. Для свободных команд выберите провайдера и введите свой ключ в панели.

Длинный ответ листается ↑/↓, «Назад» закрывает. Русская озвучка требует установленных голосовых данных Android TTS. Google и другие приложения не отключаются.
Установщик сохраняет данные через install -r; ключа автора в архиве нет.
Полная инструкция и исходники: https://github.com/vitalpvv-alt/android-tv-tools/tree/main/assistant
